- **🔥 Critical Actions**: Extracts immediate priorities that require executive attention.

- **🤝 Key Opportunities**: Highlights growth areas and successful collaborations.

**How to use**: Click the "Refresh Analysis" button to let Llama 3.2 curate your recent inbox into a strategic brief.

## 3. RAG-Powered Command Center
The Command Center is now enhanced with **Retrieval-Augmented Generation (RAG)**.

### How RAG Works:
1. **Retrieval**: When you ask a question, the system searches the **Knowledge Graph** for relevant threads and emails.
2. **Augmentation**: It injects real-time metrics (like department stress scores) into the context.
3. **Generation**: **Llama 3.2** generates a professional answer grounded *strictly* in your institutional data.

### Example Queries:
- *"What are the risks regarding NAAC accreditation?"*
- *"Who are the key coordinators for student placements?"*
- *"Which departments are currently overloaded and why?"*

## 4. Technical Requirements
To use the AI features (Curation & RAG), ensure your local environment is set up:

1. **Install Ollama**: Download from [ollama.com](https://ollama.com).
2. **Pull Llama 3.2**: Run the following command in your terminal:
   ```bash
   ollama run llama3.2
   ```
3. **Start the Server**:
   ```bash
   npm start
   ```
